# License Manager - Professional License Management System

A complete license management system with desktop client, web admin panel, Stripe integration, and automatic updates.

## Features

- 🔐 License key based authentication
- 💳 Stripe payment integration
- 📊 Admin dashboard
- 👤 User portal
- 🔄 Automatic updates
- 🌍 Multi-language (PT-BR, EN, RU)
- 🖥️ Modern desktop client (CustomTkinter)
- ☁️ Cloud hosted backend (Render)

## Prerequisites

- Python 3.9+
- PostgreSQL database
- Stripe account
- GitHub account
- Render account
